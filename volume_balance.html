How this page works

Every link carries one balanced volume. Where it comes from, in priority order:

  1. Locked: you typed it (border solid black, 🔒).
  2. Count: the link's primary observed count, grown to the base year (mode Auto).
  3. Turning movements: approach or departure sum at an adjacent intersection box.
  4. Balance: solved from conservation of flow at junctions (dashed border, italic).

Chips under a value compare it with each other evidence: counts, StreetLight approach/departure, and the flow implied by the neighbouring junction. Junctions that cannot balance show a red Δ.

Intersection boxes list the 12 movements as in the spreadsheet (top row = southbound approach ↙↓↘, bottom = northbound ↖↑↗, left = eastbound, right = westbound). Bind a box to a StreetLight source and the scenario's day type / hour drive it; typed movements override and stay orange.

Editing: drag nodes; click to edit in the side panel. The + tools stay active so you can place several nodes; Esc returns to Select. Connect: click a port on an intersection box (triangle pointing in = IN port where a link ends, pointing out = OUT port where a link starts) or a junction / terminal, then the other end; the direction follows the ports, so the click order does not matter. Shift+click on the second end also creates the opposite direction, and a link's panel has a "Create opposite direction" button. Del deletes, Ctrl+Z undoes, wheel zooms, drag empty canvas to pan.

Typing movements: every movement inside an intersection box is a small entry box; click it and type the new value (Enter saves, Tab saves and moves to the next box, Esc cancels), or use the grid in the box's panel. A typed value on a StreetLight-bound box becomes an orange override; the panel's ↺ returns it to the source.

Extra movements: an intersection panel can add U-turns, second turn lanes or any custom entry-leg → exit-leg movement the source does not carry. They count toward the approach and departure sums, so the balance sees them.

Files: the page opens with the embedded network. Open JSON… loads your network.json; Save writes back to that same file (Chrome/Edge) or downloads it. A draft is also kept in this browser.
